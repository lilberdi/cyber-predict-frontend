## Завершение через Figma Desktop
1. Откройте указанный файл в Figma Desktop.
2. Plugins → Development → Import plugin from manifest.
3. Выберите manifest.json из этой папки.
4. Запустите Plugins → Development → Cyber Predict — Finish prototype.
5. После сообщения «Готово» нажмите Present (▶). Выберите Desktop или Mobile.

Плагин не использует сеть, не отправляет данные и работает только с известной страницей Cyber Predict.
Повторный запуск заменяет связи того же типа и не создаёт дубликаты экранов.

## Реальные функции
Это кликабельная демонстрация, а не исполняемый frontend с подключённым API.
Карточки матчей и профили содержат демонстрационные данные. Метрики 65,6%, 0,657 и 0,230 взяты из сохранённого backend-артефакта elo_logreg 0.1.0, а не с работающего сервера.

Backend: https://github.com/lilberdi/cyber-predict-backend/tree/dev

| Экран | Backend |
| --- | --- |
| Матчи | GET /api/v1/matches/upcoming |
| Карточка матча | GET /api/v1/matches/:id |
| Прогноз | GET /api/v1/predictions/:id |
| Качество модели | GET /api/v1/model/metrics |
| Команды, профили, турниры | В текущем router.go нет отдельных endpoint; требуется согласовать данные |

Нынешний frontend обращается к /matches, /teams, /predictions, /tournaments и при ошибке возвращает mockData. При реализации дизайна нужно согласовать пути и DTO с backend.
